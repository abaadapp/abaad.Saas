# Abaad AI Task Synchronization Contract

## Source of truth

GitHub Issues are the canonical source of truth for Abaad development tasks.

Notion is a synchronized operational view. ChatGPT/Claude/Codex must never treat a conflicting Notion value as newer than the matching GitHub Issue.

## Identity

Every task is identified by:

`Sync Key = abaadapp/abaad.Saas#<issue_number>`

The same Sync Key must map to exactly one Notion row. Duplicate rows are an error and must not be guessed or merged silently.

## Canonical fields

The following fields must match exactly between GitHub and Notion:

- Task / GitHub Issue title
- Type: Feature | Fix
- Status
- Owner: Saad | Udai | ChatGPT
- Priority: P0 | P1 | P2 | P3
- Area / Files
- Branch
- GitHub PR
- Depends On
- Prompt
- Notes
- GitHub Issue number and URL

## AI write protocol

When ChatGPT, Claude, or Codex changes task metadata:

1. Read the current GitHub Issue first.
2. Preserve the exact Issue Form headings generated by `.github/ISSUE_TEMPLATE/abaad-task.yml`.
3. Update GitHub first.
4. Never implement directly on `main`; use the task's Branch field.
5. Do not create a second Notion row for an existing Sync Key.
6. Verify the matching Notion record after synchronization when Notion access is available.
7. If GitHub and Notion disagree, GitHub wins and Notion must be repaired from GitHub.
8. Do not silently accept malformed required fields. Stop and report the invalid field.

## Automatic synchronization

`.github/workflows/notion-sync.yml` runs on GitHub Issue changes and also performs periodic reconciliation. `scripts/sync_github_notion.py` validates enum fields, computes a canonical SHA-256 Sync Hash, and upserts Notion by Sync Key.

Required repository Actions secret:

`NOTION_TOKEN`

The token must belong to a Notion integration that has access to the Abaad Development data source.

## Drift protection

The scheduled reconciliation overwrites mirrored Notion task fields from GitHub. The Sync Hash records the hash of the canonical GitHub payload so mismatches can be detected and repaired instead of silently diverging.
